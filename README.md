# 🤖 Gemini LangChain Chatbot

> Supports streaming responses, session memory, and Dockerized CLI deployment.

## ✨ Features

- 🧠 Multi-turn memory with session history
- ⚡ Real-time token streaming output
- 🔗 LangChain prompt pipelines
- 🤖 Gemini Flash integration
- 🐳 Docker support
- 💻 Interactive CLI chatbot
